# Glossary

Process vocabulary and its Mellon names, so either name can be searched. Product terms (spell, score, creature, host) live in [AGENTS.md](../AGENTS.md), "Names and terms" (INV-002).

## Process terms

| Plain name | Mellon name | Meaning | Not to be confused with |
| --- | --- | --- | --- |
| Invariant | Elder Rune | A bedrock rule in `docs/INVARIANTS.md` (INV-001 onward) | A preference or a tunable |
| Decision record | The Red Book | Append-only rationale in `docs/DECISIONS.md` | Current state |
| Current state | Watchfire log | The rewritten present in `docs/HANDOFF.md`, at most 80 lines (INV-005) | History or changelog |
| Proof badge | Ranger mark | `[OBSERVED]`, `[DEDUCED]`, `[CONTRACT]`, `[HYPOTHESIS]`, `[UNTESTED]` (INV-003) | An unlabelled claim |
| Session loop | Fellowship quest loop | Scout, scope, build, verify, hand off (`AGENTS.md`) | A free-form chat |
| Fore-conception | Saruman's voice | A training default projected onto the repository (INV-010) | An observed fact |
| Ambiguity | Riddles in the dark | Intent or fit with several valid readings (INV-009) | A known answer |
| Clarifying question | Speak, friend | A targeted question before building (INV-009) | A post-hoc excuse |
| Loopback | Turn back at Caradhras | Returning from build or verify to scoping when a premise breaks (INV-009) | Forcing a broken plan through |
| Resistance | You shall not pass | A test, check, or file that contradicts the plan; stop and inquire (INV-007) | An obstacle to route around |
| Fence check | Doors of Durin | Finding the decision behind a guard before changing it (INV-004) | Deleting an unfamiliar guard |
| Negative proof | Sting's blue glow | A new test failing on the unfixed code first (INV-007) | A test written to pass |
| Consolidation | Elven sleep | Distilling lessons into dense rules (INV-008) | Lossy summarizing |
| Dense prose | Mithril prose | One declarative rule under 25 words | Discursive explanation |
| Lexical firewall | No Black Speech | No em dashes in prose, comments, commits (INV-006) | UI typography |
| Held tension | Two watchtowers | Two true claims that do not fit yet (`T-NNN`) | An open question or a decision |
| Zone | Realm border | One repository and its rules | A branch, folder, or chat thread |
| Fresh session | New traveler | A context with no memory of earlier sessions | A defect |
